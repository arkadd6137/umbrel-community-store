# Semisi's Umbrel Community App Store

Add this repo URL in umbrelOS: App Store → ⋯ → Community App Stores.

## Apps
- `semisi-qbittorrent-vpn` — qBittorrent (hotio image, same as the official Umbrel app) with hotio's built-in WireGuard VPN for Private Internet Access, auto port forwarding and a firewall kill switch.

No credentials live in this repo. Set `VPN_PIA_USER` and `VPN_PIA_PASS` in Umbrel: app Settings → Advanced → Environment variables → Custom variables (service `server`).
